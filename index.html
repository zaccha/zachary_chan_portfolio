Select Health · Salesforce Marketing Cloud

Agent Seminar Registration System

Problem
Checking license-state eligibility, tracking capacity, and sending reminders for agent seminars didn't scale as a manual process.
Built
A personalized email link opens a secure CloudPage, which looks up the agent's Salesforce contact and license data to filter eligible seminars. Salesforce campaigns track registration and capacity for each seminar, and one dynamic template sends confirmations.
Tools
Salesforce Marketing Cloud, CloudPages, Journey Builder, Salesforce CRM, AMPscript
Impact
Replaced manual eligibility and capacity checks with an automated, CRM-connected registration flow — plus week-before and day-before reminder journeys and one-click Google, Outlook, and ICS calendar links.
